# ❄️ Snowfall Animation

A small interactive **Snowfall Animation** project built with **HTML, CSS, and JavaScript**.

I created this project mainly as a hands-on exercise to apply the **DOM manipulation and event-handling concepts** I learned in JavaScript. Instead of following a tutorial and copying an animation, I used the project to experiment with creating elements dynamically, modifying their properties, handling events, and controlling animations through JavaScript.

## 🎯 Purpose

The main goal of this project was to strengthen my understanding of the **DOM and JavaScript events** by building something interactive.

Through this project, I practiced:

* Creating and adding elements dynamically
* Selecting and manipulating DOM elements
* Modifying element styles through JavaScript
* Adding and handling event listeners
* Working with mouse events
* Using event properties such as `clientX` and `clientY`
* Creating and controlling animations with JavaScript and CSS
* Removing elements from the DOM
* Using timers and animation-related logic
* Connecting JavaScript behavior with CSS animations

## ✨ Features

* Animated snowfall effect
* Dynamically created snowflakes
* Snowflakes fall at different positions and speeds
* Interactive mouse events
* Snowflakes can react to mouse interaction
* Snow particles can disappear and create a dust-like effect
* Uses JavaScript to control DOM elements and their behavior

## 🛠️ Technologies Used

* **HTML5** — Structure
* **CSS3** — Styling and animations
* **JavaScript** — DOM manipulation, event handling, and animation logic

## 🧠 Concepts Practiced

This project was primarily built to practice the JavaScript concepts I had recently learned.

### DOM Manipulation

* `className & classList`
* Creating elements with `createElement()`
* `appendChild()`
* Modifying styles
* Working with element properties
* Removing elements from the DOM

### Event Handling

* `addEventListener()`
* Mouse events
* Event objects

* `event.clientY`
